## Example 1: brief/brief-result.md (external briefing output)

```markdown
# Site Strategy: StockFlow

## 1. Business Overview
- **Company:** StockFlow
- **What we do:** Cloud-based inventory management software for small e-commerce businesses (1–50 employees)
- **Business model:** B2B SaaS (subscription-based)
- **Core problem we solve:** Small retailers struggle to track inventory across multiple sales channels (Shopify, Amazon, physical store) and often oversell or understock
- **Competitive advantage:** Simplest setup (connects in 10 minutes), lowest price ($29/mo vs. competitors $199+), best customer support (48h response)

## 2. Target Audience
- **Primary persona:** E-commerce Store Owner (age 28–45, bootstrapped or small team)
- **Their main goal:** Automatically sync inventory across all sales channels without manual work
- **Their pain points:**
  - Manual inventory tracking is error-prone and time-consuming
  - Overselling causes customer refunds and reputation damage
  - Can't see real-time stock levels across platforms
  - Don't want to hire inventory manager
- **Decision-making process:** Owner researches online, reads reviews on G2, compares pricing, tests with free trial

## 3. Website Objectives
- **Primary goal:** Generate qualified leads for free trial signups
- **Secondary goals:** Build SEO authority for "inventory management software" keywords
- **Primary conversion action:** "Start Free Trial" (no credit card required)
- **Success metrics:** 500 signups/month, 20% conversion rate from visitor to trial
- **Timeline:** Live in 4 weeks

## 4. Competitive Context
- **Main competitors:**
  - TradeGecko (enterprise-focused, $300+/mo, complex)
  - Cin7 (mid-market, $150+/mo)
  - Shopify native inventory (basic, limited)
- **Market positioning:** "Simplest inventory management for small e-commerce" (not "most powerful")
- **Industry category:** SaaS (B2B, subscription)

## 5. Visual & Tone Direction
- **Existing brand:** None (startup)
- **Visual tone:** Modern, approachable, trustworthy (not flashy, not generic)
- **Reference websites:**
  - Wave Accounting (simple, clean, friendly)
  - Notion (minimal, powerful, accessible)
  - Zapier (clear benefit communication)
- **Multilingual:** No (English only for MVP)

## 6. Key Pages & Sections (Draft)
- **Home:** Hero positioning + free trial CTA + 3 key features + social proof + final CTA
- **Features:** Detailed feature showcase + comparison with manual tracking
- **Pricing:** Simple 3-tier or single plan + FAQ + contact
- **How It Works:** Step-by-step onboarding preview
- **Blog:** SEO content around inventory management, e-commerce, supply chain
- **Contact:** Sales inquiry form

## 7. Success Criteria
- The site should feel: **professional but accessible** (not enterprise, not startup chaos)
- Should communicate: **"We understand your specific problem and made something just for you"** in 5 seconds
- Should convert: **30% of visitors to free trial signup or contact form**
```

## Example 2: BRAND_IDENTITY.md (from brand-identity-creation)

```markdown
# Brand Identity: StockFlow

## 1. Brand Positioning
- **Positioning:** StockFlow is the simplest inventory management software for small e-commerce businesses
- **Audience:** E-commerce store owners who want simplicity over power
- **Visual tone:** Modern, approachable, trustworthy
- **Industry psychology:** SaaS software requires trust (blue) + approachability (friendly design)
- **Competitive signal:** Not enterprise (no navy corporate blue), not startup chaos (no vibrant colors)

## 2. Color System

### Primary Color: Blueprint Blue
- **Hex:** #2563EB
- **RGB:** 37, 99, 235
- **Usage:** Primary buttons, headlines, key navigation, links
- **Rationale:** 
  - SaaS standard (signals reliability)
  - Unique enough to avoid generic tech feeling
  - 4.5:1 contrast on white (accessible)
  - Works across light/dark backgrounds

### Secondary Color: Emerald Green
- **Hex:** #10B981
- **RGB:** 16, 185, 129
- **Usage:** CTAs (free trial button), success messages, checkmarks, positive metrics
- **Rationale:**
  - Green = growth, go, success (psychological trigger for "start free trial")
  - Complements blue without competing
  - Creates clear CTA hierarchy

### Neutral Gray Palette
- **Darkest (#1F2937):** Headlines, primary text, strong UI elements
- **Dark (#374151):** Secondary text, labels, borders
- **Medium (#6B7280):** Disabled text, muted elements, fine print
- **Light (#D1D5DB):** Input borders, subtle dividers, disabled backgrounds
- **Lightest (#F3F4F6):** Page background, card backgrounds, hover states

### Status Colors
- **Success:** #10B981 (same as secondary, extends usage)
- **Error:** #EF4444 (red, standard)
- **Warning:** #F59E0B (orange, standard)
- **Info:** #0EA5E9 (light blue, complements primary)

## 3. Typography

### Heading Font: Poppins
- **Why:** Geometric, modern, friendly (not corporate or futuristic)
- **Weights used:** 600 (headers), 700 (main headlines)
- **Sizes:**
  - H1: 48px (hero headlines)
  - H2: 36px (section headlines)
  - H3: 28px (subsection)
  - H4: 20px (card titles)

### Body Font: Inter
- **Why:** Excellent readability on screen, clean, neutral personality
- **Weights used:** 400 (body text), 600 (emphasis/labels)
- **Sizes:**
  - 16px: Paragraph text (desktop)
  - 14px: Secondary text, captions
  - 14px: Small labels
  - 12px: Fine print, metadata

### Type Scale (1.125x ratio)
```
Display (rare): 64px
H1 (hero): 48px
H2 (section): 36px
H3 (subsection): 28px
H4 (card): 20px
Body: 16px
Small: 14px
Tiny: 12px
```

### Line Heights
- **Headings:** 1.2 (tight, punchy)
- **Body:** 1.6 (loose, readable)
- **Captions:** 1.4 (balanced)

## 4. Spacing Scale (8px Base)
```
--space-1: 4px    (tiny gaps, icon spacing)
--space-2: 8px    (input padding, small gaps)
--space-3: 12px   (card title margin)
--space-4: 16px   (standard padding, button padding)
--space-5: 24px   (card padding, section gaps)
--space-6: 32px   (section padding, layout gaps)
--space-7: 48px   (major section spacing)
--space-8: 64px   (hero padding, large layouts)
--space-9: 96px   (top page padding, max spacing)
```

## 5. Border Radius
```
--radius-sm: 4px     (inputs, small UI)
--radius-md: 8px     (buttons, medium elements)
--radius-lg: 12px    (cards, larger surfaces)
--radius-xl: 16px    (hero sections, special)
--radius-full: 9999px (pills, circles)
```

## 6. Shadows
```
--shadow-sm: 0 1px 2px rgba(0,0,0,0.05)
  Used for: Cards on light backgrounds, subtle depth

--shadow-md: 0 4px 12px rgba(0,0,0,0.08)
  Used for: Cards on hover, dropdown menus

--shadow-lg: 0 12px 24px rgba(0,0,0,0.1)
  Used for: Modals, overlays, hero sections

--shadow-xl: 0 20px 40px rgba(0,0,0,0.12)
  Used for: Special emphasis, important elements
```

## 7. Visual Tone & Guidelines

### Design Principles
- **Simplicity first:** Every element serves a purpose
- **Approachable professionalism:** Modern but not trendy
- **Trustworthy:** Consistent, predictable, reliable
- **Spacious:** Generous padding, breathing room between elements
- **Clear:** High contrast, legible typography, obvious CTAs

### Color Distribution
- Primary blue: 40–45% (headlines, primary buttons, links)
- Secondary green: 5–10% (CTAs, success states)
- Neutral grays: 40–50% (text, backgrounds, UI)
- White: 5–10% (negative space)

### Tone in Practice
- **Do:** "Sync inventory from Shopify, Amazon, and your store in one view"
- **Don't:** "Revolutionize your supply chain management"
- **Do:** Clean, organized card layouts
- **Don't:** Decorative gradients, animations for effect

### Usage Rules
- Primary color is used for:
  - Main headlines
  - Primary buttons only
  - Navigation active states
  - Important links
- Secondary color ONLY for:
  - "Start Free Trial" button
  - Success messages
  - Positive metrics
  - Call-to-action emphasis
- Neutrals dominate:
  - Body copy
  - Backgrounds
  - Borders
  - Supporting UI

### Do's & Don'ts
✓ Use consistent button styling
✓ Maintain hierarchy with color + size
✓ Use status colors for system feedback
✓ Keep spacing predictable
✓ Ensure 4.5:1 contrast for accessibility

✗ Don't use color decoratively
✗ Don't mix multiple accent colors
✗ Don't use arbitrary sizing
✗ Don't add new brand colors
✗ Don't break spacing scale for "visual balance"

## 8. Component Color Defaults

### Buttons
- **Primary button:** Background #2563EB, white text
- **Secondary button:** Border #2563EB, transparent background, blue text
- **CTA button (Free Trial):** Background #10B981, white text
- **Hover state:** Darken primary color by 10%
- **Disabled state:** Gray background, muted text

### Forms
- **Input border (default):** #D1D5DB (light gray)
- **Input border (focus):** #2563EB (primary blue)
- **Input border (error):** #EF4444 (red)
- **Label text:** #1F2937 (dark gray)
- **Placeholder text:** #9CA3AF (medium gray)

### Cards
- **Background:** White (#FFFFFF)
- **Border:** #E5E7EB (light gray)
- **Shadow:** shadow-sm on light background
- **Hover shadow:** shadow-md

### Links
- **Default:** #2563EB (primary blue)
- **Visited:** #7C3AED (purple, accessible alternative)
- **Hover:** #1D4ED8 (darker blue)
- **Focus outline:** 2px solid #2563EB

### Status Messages
- **Success:** #10B981 text on white background
- **Error:** #EF4444 text on white background
- **Warning:** #F59E0B text on white background
- **Info:** #0EA5E9 text on white background

## Example 4: AGENTS_PROJECT.md (from design-system-builder)

```markdown
# Design System Rules: StockFlow

All design and development work must follow these rules.

## 1. Design Tokens Reference

[All tokens from BRAND_IDENTITY.md, linked with CSS variable names]

### Color Quick Reference
- Primary CTA: #2563EB (blue)
- Free trial button: #10B981 (green)
- Text: #1F2937 (dark gray)
- Backgrounds: white or #F9FAFB (light gray)
- Borders: #E5E7EB (light gray)

### Typography Quick Reference
- Headings: Poppins, 600–700 weight
- Body: Inter, 400 weight
- Type scale: 48px (H1), 36px (H2), 28px (H3), 20px (H4), 16px (body)

## 2. Component Library

### Button Component
```
.button (base class)
├── .button--primary (blue background, white text)
├── .button--secondary (blue border, transparent bg)
├── .button--cta (green background, white text) ← Free trial button
├── .button--large (bigger padding)
├── .button--small (smaller padding)
└── .button--full (100% width)
```

**Rules:**
- Primary buttons for secondary actions
- CTA buttons (green) ONLY for free trial signup
- All button padding from spacing tokens
- Hover state: darker color
- Disabled state: gray with 50% opacity

### Card Component
```
.card (base class)
├── .card--surface (light background)
├── .card--feature (icon + title + description)
└── .card--metric (large number + label)
```

**Rules:**
- Base card: white background, light border, shadow-sm
- Padding: 24px (all sides)
- Hover: increase shadow to shadow-md
- Content hierarchy: icon/image → title → description

### Section Patterns
```
.section (base padding)
├── .section--hero (extra padding, full-width)
├── .section--alt (light background)
└── .section--cta (centered, emphasis)

.container (max-width wrapper)
.section__inner (flex container)

.grid (multi-column layout)
├── .grid--auto (auto-fit columns)
├── .grid--2-col (2 equal columns)
└── .grid--3-col (3 equal columns)
```

**Rules:**
- Section padding: 64px desktop, 48px tablet, 32px mobile
- Container max-width: 1200px
- Container padding: 32px horizontal
- Grid gaps: 24px (use spacing tokens)

### Form Components
```
.form-group (wrapper)
├── .form-label (label)
├── .form-input (text inputs)
├── .form-textarea (multi-line)
├── .form-select (dropdown)
└── .form-actions (button group)

.form-error (validation message)
.form-success (success message)
```

**Rules:**
- Input border: 2px solid, light gray by default
- Input focus: primary blue border
- Input error: red border
- Label: bold, above input, required marker if needed

### Header / Navigation
- Logo on left
- 5–6 nav items centered or right-aligned
- Mobile: burger menu (hidden on desktop)
- Active link: primary blue color
- CTA button: green "Start Free Trial"

## 3. Layout Patterns

### Two-Column (Text + Visual)
- Left: content (400–500px max)
- Right: image or chart
- Vertically centered
- Desktop: side-by-side
- Mobile: stacked

### Card Grid
- Desktop: 3 columns
- Tablet: 2 columns
- Mobile: 1 column
- Gap: 24px

### Hero Section
- Full viewport height or tall section
- Background: white or light gray
- Content centered or left-aligned
- Heading + subheading + CTA
- Optional: background image or shape

### CTA Section
- Background: primary blue or light gray
- Content centered
- Heading + supporting text + button
- Higher contrast than other sections

## 4. Spacing Discipline

All spacing must come from tokens (4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px).

**NEVER use:**
- `margin-top: 37px`
- `padding: 15px`
- `gap: 20px`

**USE:**
- `margin-bottom: var(--space-4)` (16px)
- `padding: var(--space-5)` (24px)
- `gap: var(--space-5)` (24px)

**Grid gaps come from section layout:**
```scss
.grid {
  gap: var(--space-5); // 24px
}
```

**Never add margins to individual child elements:**
```scss
// BAD
.card {
  margin-top: 30px;
}

// GOOD
.grid {
  gap: var(--space-5); // All spacing controlled here
}
```

### Primary Blue (#2563EB) ~40% of design

### Secondary Green (#10B981) ~5% of design
- "Start Free Trial" button ONLY

### Neutrals #80–90% of design

### Status Colors ~1% of design
- Error: red
- Warning: orange
- Info: light blue
- Success: green

**Rule:** Do not add new colors. Use the system.

## 6. Typography Rules

### Headings
- Font: Poppins
- Weight: 600–700
- Line height: 1.2
- Letter spacing: -0.02em (for large sizes only)
- Size: Use type scale (48px, 36px, 28px, 20px)

### Body Text
- Font: Inter
- Weight: 400
- Line height: 1.6
- Font size: 16px minimum
- Color: neutral-700 (secondary text) or neutral-900 (primary)

### Emphasis
- Use 600 weight (semibold), not italics
- Keep emphasis minimal
- Use color (primary blue) for important terms

**Typography Hierarchy:**
```
H1: Biggest, boldest (page headline)
H2: Section headline
H3: Subsection
H4: Card title
Body: Regular paragraph
Small: Captions, metadata
```

## 7. Responsive Behavior

### Breakpoints
- Mobile: 0–480px
- Tablet: 481–768px
- Desktop: 769px+

### Grid Collapse
```
Desktop: 3 columns → Tablet: 2 columns → Mobile: 1 column
```

### Spacing Reduction
```
Section padding: 64px → 48px → 32px
Container padding: 32px → 24px → 16px
Grid gaps: 24px → 16px → 12px
```

### Mobile Specific
- Hero headings: reduce from 48px to 36px
- Two-column layouts: stack to one column
- Cards: become full-width
- No layout hacks (no negative margins, no absolute positioning)

## 8. Accessibility Standards

### Colors
- 4.5:1 contrast minimum on text
- Primary blue on white: passes
- Button text: always visible with good contrast

### Forms
- Labels required above inputs
- Focus states clearly visible (blue outline)
- Error messages in red + icon
- Placeholder text: not a label

### Images
- All images have descriptive alt text
- Decorative images: empty alt=""

### Navigation
- Keyboard navigation working
- Active page highlighted
- Focus states visible

## 9. Non-Negotiables

✓ Use component classes, never custom styles
✓ All spacing from tokens only
✓ All colors from token palette
✓ No layout hacks
✓ No hardcoded heights
✓ Use grid/flex + gap for layout
✓ Every section aligns to composition system
✓ No visual guessing
✓ Mobile responsive by default
✓ Accessibility built-in
```

## Key Takeaway

All 5 documents create a **complete system** where:

1. **brief/brief-result.md** answers: "What are we building and why?"
2. **BRAND_IDENTITY.md** answers: "What does it look like and feel like?"
3. **_vars.scss** answers: "What are the exact token values for implementation?"
4. **AGENTS_PROJECT.md** answers: "What rules do we follow for design consistency?"
5. **SITE_STRUCTURE.md** answers: "What pages do we need and what goes on each?"

No skill is used in isolation — they're always referenced together. This eliminates arbitrary design decisions and ensures every project feels intentional, consistent, and strategic.
